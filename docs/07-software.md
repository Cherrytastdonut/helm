# 소프트웨어 현황

현재 확보된 실행 코드는 CAD 생성·도면 추출·렌더링·검증·패키징 도구입니다. 주행 펌웨어, 자율주행/점검 프로그램, 서버, FlutterFlow 앱 완성본은 제공 자료에서 확보되지 않았습니다.

다음은 개발 준비 목록이며 완료 이력이 아닙니다.

| 인터페이스 | 먼저 정할 것 |
|---|---|
| Jetson ↔ ESP32 | 연결 방식·메시지·주기·타임아웃·정지 동작 |
| 주행 | 실제 MDD10A 핀/레벨, 엔코더 단위·방향 |
| 센서 | 드라이버 버전·연결·좌표계·시간 기준 |
| 카메라 서보 | 중립·방향·기구 허용 범위·전원 조건 |
| 범퍼/E-STOP | 하드웨어 차단과 소프트웨어 감지 역할 |
| 로그/화면/경보 | 표시·저장·오류·통신 끊김 처리 |

실물 인터페이스 표 → 장치별 읽기·정지·오류 시험 → 저수준 통신 → 확인한 기능 통합 → 점검 시나리오/화면 확정 순서로 진행합니다. 근거 없이 ROS/JetPack 버전이나 GPIO 번호를 확정하지 않습니다.

실제 코드가 생기면 실행 방법·의존성·검사 결과를 이 문서와 함께 추가하세요. [CAD 코드 재현](12-reproduce.md)
