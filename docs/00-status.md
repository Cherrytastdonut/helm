## 다음 순서

1. 동봉 혼과 MG995/MG996 브래킷의 위·옆 사진 및 구멍 간격·두께·장착 높이를 기록합니다.
2. 혼 연결을 확정하고 기존 카메라 볼트·너트 간섭을 실제 체결품에 맞춰 수정합니다.
3. SSD·배전 단자대·열화상 보드와 나머지 가정부품을 실제 보유품에 대조합니다.
4. 움직임·케이블·강도·공구 접근·배터리 인출을 확인합니다.
5. 동일 리비전 STEP/DXF/PDF/BOM으로 재단도를 확정합니다.
6. 시험 조각 → 가조립 → 전원/핀맵 확인 → 단계별 동작 확인을 기록합니다.
