# 재단·가공 가이드

현재는 종이 대조·실측 단계입니다. 혼 연결, 기존 체결부 간섭, 포맥스 강도와 실제 체결품을 확인한 뒤 재단도를 확정합니다.

## 지금 할 일

1. [최신 PDF](../drawings/procurement-review/HELM_CURRENT_FLAT_PROFILES_REVIEW_A3.pdf)를 A3·실제 크기 100%로 출력합니다. 20쪽 모두 검토용이며 페이지 맞춤은 해제합니다.
2. 기준선을 재어 100 mm인지 확인합니다.
3. 실물 모터 플랜지와 대조하고 혼·브래킷 치수를 기록합니다.
4. 차이가 있으면 CAD를 수정합니다. 임의로 구멍을 늘려 끼우지 않습니다.

## 확정 뒤 가공 순서

부품명·리비전·STEP/DXF·두께 맞추기 → 판재에 번호/앞면/기준 모서리 표시 → 시험 조각에서 절삭 폭/구멍 확인 → 판 고정 → 절단/천공 → 줄·사포 마감 → 가조립·측정 기록.

- 구매한 5T 포맥스 600×900 mm 2장이 기준입니다. 현재 128개 제작 부품이 모두 두 장에서 단순 절단되는 부품이라는 뜻은 아닙니다.
- 3D 브래킷의 최대 깊이를 평판 두께로 오인하지 않습니다. 홈·단차는 STEP으로 확인합니다.
- V13 PDF를 종이에 대고 재단하지 않습니다. DXF에는 공구 경로나 절삭 폭이 반영되지 않았습니다.
- 전체 판재 배치/수량 최적화는 미완료입니다. 공구 여유는 시험 조각 결과를 반영합니다.
- 판을 받침판에 고정하고 보유 칼·톱으로 나누어 가공합니다. 손으로 들고 천공하지 않습니다.
- Bosch 2607010529 구성은 2/3/4/5/6/8 mm입니다. D4.5 도면과 맞지 않으므로 가공법과 설계를 함께 확정합니다. 임의로 D5로 넓히지 않습니다.
- 전산볼트는 고정해 자르고 끝단을 정리하며, 미리 끼운 너트로 나사산 통과를 확인합니다. 실물 너트·와셔에 맞춰 길이를 확정합니다.

포맥스 플랜지 주변의 좁은 부분, 너트의 직접 지지와 구멍 가장자리 남는 폭은 강도 검토 대상입니다. 보유 금속 브래킷 호환 확인 전에는 평판 검토 형상을 최종 하중 지지구조로 확정하지 않습니다.

전원 백플레이트 등 깊이 형상은 STEP으로 확인합니다. 20개 평면 도면 중 CUSTOM_5V_DISTRIBUTOR는 1.6 mm 가정 분배기판으로 5T 포맥스 가공 대상이나 확정 회로 제작 도면이 아닙니다. [현재 파일](03-cad.md)을 기준으로 재료·수량을 대조합니다.
