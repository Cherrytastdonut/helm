# CAD·설계도 읽는 법

현재 **MEASURED_LAYOUT_20261006**은 3,888개 노드의 실측 반영 검토본입니다. [상세 변경](16-measured-layout.md)과 [현재 CAD 복원](11-artifacts.md)을 먼저 확인해 주세요.

| 파일 | 사용 범위 |
|---|---|
| 전체 STEP | 전체 조립체 배치. mm 단위 |
| EDITABLE/HELM_WORK | 현재 BREP 3,888개와 관계 메타데이터. 원 제조사 전체 피처 이력은 아님 |
| 제작 STEP 128개 | 전체 좌표를 유지한 3D 홈·깊이. 모두 포맥스 재단품은 아님 |
| 변경 STEP 26개 | 꺽쇠·카메라·패드·측판·로커. 제작 후보와 일부 중복 |
| 선택 재고 STEP 3개 | 부스바·MG995 두 프레임의 외접 상자. 미설치, 상세 제조 CAD 아님 |
| DXF 20개 | 일정 두께 관통 윤곽. 19개 5T + 1개 1.6T 분배기판 참조 |
| A3 윤곽 20쪽 | 실제 크기 100%, 페이지 맞춤 해제 후 100 mm 선 확인 |
| 섀시 4홀 확인지 | 실물에 대조하는 중심점. 본판 재단 도면 아님 |

꺽쇠의 실제 홀·두께·리브, C920 힌지 상대 자세, 로커 내부 깊이 분할, 혼 연결부는 미확정입니다. 고정 부품 홀은 실물을 놓고 전사합니다. 깊이가 다른 형상을 평판으로 납작하게 가공하지 않습니다.

과거 V13(4,102개), SER0063(4,152개), PROCUREMENT(4,078개) 파일은 이력입니다. 현재 파일을 덮어쓰거나 과거 변경 스크립트를 반복 적용하지 않습니다.
