## 변경 내용

C715 512GB를 실제 2280 위치에 배치하고 2242 참조·선택형 2230 SSD를 제거했습니다. CP003는 100×45×33 mm 외곽만 적용했고 고정홀·단자를 추정하지 않았습니다. 전원판은 구형 닫힌 홀 3개를 메우고 하단 7×8 mm 홈 2개를 추가했습니다. 깊이 형상은 STEP에 보존합니다.

열화상 제조사 본체 215개를 대조·유지하고 PH2.0 정보를 정정했습니다. 미구매 ADC 받침·체결품·가짜 연결을 제외했습니다. 이번에 77개 노드를 제거하고 3개를 추가했으며 기존 전원판 1개를 수정했습니다. 입력의 4,074개 BREP는 바이트 단위로 유지했습니다. 새 18개 경로를 무효 처리했습니다.

SSD PCB·키·칩은 명목 결합 모델입니다. 복원 시 카드 입구에 0.03 mm 명목 여유를 두었으며 정확한 공급사 PCB 제조 도면이 아닙니다. 최종 체결·끼움은 실물 확인 대상입니다.

앞선 SER0063 몸체·지지부를 유지합니다. 원본 플랜지 홀 D4.5·피치 48×10 mm, 팬 장착판 72×60×5, 틸트 장착판 72×49×5 mm입니다. 카메라 높이 +24.38 mm, 오른쪽 지지판 +11 mm 변경을 유지합니다. 혼 공간 2 mm는 가정이며 실측값이 아닙니다. 전산볼트 검토 길이 64×4 + 38×4 + 20×8 = 568 mm는 절단 손실·실물 너트 차이 미포함입니다.

## 파일 역할

- 전체 STEP: 전체 조립체 배치·관계. [ZIP 복원](11-artifacts.md) 뒤 엽니다.
- EDITABLE/HELM_WORK: 현재 BREP와 메타데이터. 모든 제조사의 원래 피처 이력은 아닙니다.
- 개별 STEP: 전체 조립 좌표를 유지한 3D 홈·단차·깊이.
- DXF: mm, 절삭 폭·끼워맞춤 공차 미반영. 부품별 추출/보류 이유는 인덱스를 확인합니다.
- 현재 A3 윤곽 PDF: 20쪽 모두 1:1 종이 대조용. 실제 크기 100%와 100 mm 기준선 확인이 필요합니다.
- 안내 PDF/PNG: 배치 설명용. 이미지에서 치수를 재지 않습니다. 표시 색과 실물 색은 다를 수 있습니다.
