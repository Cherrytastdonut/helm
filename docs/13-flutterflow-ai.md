# FlutterFlow AI에 전달할 요구사항

과거 사용자 요청을 이어가기 위한 **새 화면 요구사항 초안**입니다. 기존 앱이나 서버가 구현되었다는 의미가 아닙니다. 아래 블록을 복사해 사용할 수 있습니다. 먼저 [현재 상태](00-status.md)와 [소프트웨어 현황](07-software.md)을 함께 제공합니다.

```text
HELM 로봇의 제작 준비와 점검 기록을 확인하는 한국어 앱 화면을 설계해 주세요.

프로젝트의 확인된 상태:
- 현재 CAD는 SER0063 모터 교체 검토본이며 제조 승인본이 아닙니다.
- 1차 구매는 이전 CSV의 29품목, 2차 구매는 새 XLSX 2주차의 64행입니다.
- 보유 부품만 사용합니다. 2차 품목 전부 장착은 요구사항이 아닙니다.
- 판재는 5T 포맥스 600×900 mm 2장입니다. 합판으로 표시하지 마세요.
- 혼 실측, 기존 카메라 체결부 간섭, 강도, 전원·핀맵·배선 확인이 남아 있습니다.
- 주행 펌웨어·서버 API·실시간 통신 사양은 아직 확보되지 않았습니다.

만들 화면:
1. 홈: 현재 리비전, 제작 승인 여부, 남은 작업, CAD 미리보기, 도면 바로가기.
2. 보유 부품: 1차/2차, 원본 행 번호, 모델, 수량, 적용 여부, 실측 여부, 근거 링크.
3. CAD·도면: V13 기준본과 SER0063 검토본을 구분해 PDF/STEP/DXF/ZIP 안내 표시.
4. 제작 준비: 실측→CAD 수정→간섭·배선 검증→재단도 확정→가조립 순서와 확인 기록.
5. 미해결 항목: 혼·브래킷, 기존 체결부 간섭, 실제 부품 대조, 전원·배선.
6. 조립·시험 기록: 날짜, 리비전, 측정값, 사진, 결과, 후속 조치.

표시 규칙:
- 확정, 공칭, 추정, 미확정, 미실시를 구분하세요.
- 검사한 팬 ±45°/틸트 ±20°를 승인된 동작 범위로 표시하지 마세요.
- 미측정 값을 0, 정상, 완료로 바꾸지 마세요. 비어 있는 상태를 지원하세요.
- 실제 통신 연결 전에는 모든 예시 데이터를 '데모'로 표시하세요.
- 하드웨어 동작 버튼이나 실시간 상태를 실제 작동하는 기능처럼 만들지 마세요.
- 앱 화면의 정지 표시는 하드웨어 E-STOP을 대신하지 않습니다.
- 실제 API, 로그인, 저장소, 다운로드 주소는 연결 사양 확정 후 적용하세요.
- 비공개 GitHub/Drive 토큰을 클라이언트 코드나 화면에 넣지 마세요.

```
