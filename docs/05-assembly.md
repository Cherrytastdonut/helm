# 조립 순서

기존 PDF 201쪽의 구조를 최신 검토 상태에 맞춰 정리했습니다. 전원 분리 상태에서 기구 장착·배선 식별을 진행합니다.

| 순서 | 작업 | 확인할 것 |
|---|---|---|
| 1 | 확정 부품 가공·마감 | 번호·두께·리비전 |
| 2 | 섀시·하부 프레임 가조립 | 기존 체결홀·패드·하부판·지지봉 |
| 3 | 배터리·전원 백플레이트 | 스토퍼·스트랩·단자 접근·후면 인출 |
| 4 | 상부 데크·패널 | 와셔 지지·너트·서비스 면 접근 |
| 5 | 제어부·센서 | 실물 홀·스페이서·커넥터 방향 |
| 6 | LiDAR 타워 | 수평·지지·배선·스캔 영역 |
| 7 | 카메라·고정 열화상 | 최신 모터 기준, 혼·간섭 해결 후 |
| 8 | 범퍼·스위치·조작부 | 이동·복귀·스위치 동작 |
| 9 | 하네스 가배치 | 궤도·가동부·모서리·플러그 접근 |
| 10 | 전기 확인·단계별 시험 | 측정값과 판정 기록 |

기존 배터리 설계는 두 스트랩과 뒤쪽 -X 인출을 의도합니다. 보유 벨크로/스트랩의 수량·폭·길이, 단자 접근, 배선 후 인출 가능 여부를 확인합니다.

카메라는 새 모터 몸체·지지부 검사와 별개로 기존 볼트·너트 간섭이 남아 있습니다. [부품별 위치](10-open-items.md)를 확인하세요. 혼 없이 모터가 구조를 구동한다고 가정하지 않습니다.

최종 조임 전 손으로 천천히 움직여 걸림, 공구 접근과 케이블 여유를 봅니다. 재료별 조건이 확정되지 않은 상태에서 일괄 체결 토크를 임의 지정하지 않습니다.
