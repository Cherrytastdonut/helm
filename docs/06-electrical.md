# 배선·전원 준비

CAD의 배선 의도와 미해결 항목입니다. 완성된 결선도나 확정 핀맵이 아닙니다.

12V AGM 배터리, 메인 퓨즈/스위치, 분기 보호·배전, 모터 차단 릴레이/E-STOP, 연산용 승압부, 5V 보조 전원부가 구매·CAD 자료에 있습니다. 실제 연결·정격은 부품 자료와 실측으로 확인합니다.

| 항목 | 현재 문제 | 완료 조건 |
|---|---|---|
| SER0063 2개 | 구형 4.8V 메모 사용 불가 | 제조사 5-8.4V 범위, 공급 전압·공유 부하·동시 전류 확인 |
| 서보 2개 배선 | 이전 경로 제거 | 실제 리드선 출구·극성·신호 리턴·움직임 루프 |
| C920 USB | 높이 변경 뒤 경로 제거 | 팬/틸트 움직임·굽힘·고정·플러그 접근 |
| RPLIDAR | 기존 배선표에 경로 없음 | 실제 케이블·Jetson 인터페이스·스캔 영역 밖 경로 |
| ADS1115 | 구매 목록에 없어 받침·체결품·가짜 연결 제거 | 보유 부품 기준 전압 취득 회로 확정 |
| 전압 분압 입력 | 보조 퓨즈 요구가 형상에 직렬 반영되지 않음 | 보유 보호부품·정격·연결 반영 |
| 배전 | CP003 외곽 적용, 기존 BUS 포트 좌표/경로 무효 | 단자 방향·정격·기구 위치·분기 식별 |
| 릴레이/E-STOP/퓨즈 | 실물 동작 미검증 | 접점·코일·억제소자 방향·선재·정격·차단 확인 |
| 커넥터 | 외형·접근 방향 참조 | 실제 키·공동·엔코더/모터 핀·극성 확인 |

SER0063 제조사 출처: https://www.dfrobot.com/product-2787.html (2026-09-30 확인). CAD 모양으로 핀 번호를 추정하지 않습니다.

[wires.json](../data/procurement-review/wires.json)의 앞선 SER0063 수정에 따른 세 경로는 NOT_RELEASED_SER0063_REPLACEMENT입니다. [ports.json](../data/procurement-review/ports.json)의 새 서보 리드선은 UNMEASURED_LEAD_EXIT입니다. 다른 기존 경로도 전체 실물 검증을 새로 완료한 것이 아닙니다.

과거 [배선표](../data/v13-baseline/WIRING_TABLE.csv)와 PDF 183쪽 E-211은 문제 추적용입니다. 단자 식별 → 전원 분리 상태 배선/단락 확인 → 부하 연결 전 출력 전압/극성 확인 → 회로별 단계 확인 → 차단/비상정지 → 가동부 케이블 확인을 기록합니다.

## 구매품 반영에 따른 현재 배선 상태

이번 리비전에서 배전 15개, 열화상 1개, ADC/전압취득 2개, 총 18개 경로를 무효 처리했습니다. geometry_valid=false, points=[], 길이 미확정이며 앞선 서보 2개·C920 경로 보류도 유지합니다. [이전 경로 기록](../data/procurement-review/SUPERSEDED_ROUTES.json).

열화상은 PH2.0 4핀입니다. GND/VCC/SDA/SCL 기능은 확인했지만 실제 결합 방향·핀 순서와 케이블 출구를 대조해야 합니다. 잘못된 2.54 mm 결합 플러그를 제거했습니다.

CP003 입력 2/출력 8에 예전 14개 논리 접속점을 임의 배정하거나 한 단자에 복수 전선을 넣지 않습니다. 내부 극 그룹과 필요한 분기 수부터 확인합니다. 판매 페이지 정격 표기도 서로 달라 전기 정격을 확정하지 않았습니다. 1차 부스바를 함께 사용하려면 그 규격과 내부 연결부터 확인합니다.
